# Controle de Notas

Sistema simples de controle de notas de alunos, desenvolvido em Python.

## Objetivo

Permitir o cadastro de alunos, o lançamento de suas notas e o cálculo
da média final, indicando a situação do aluno (aprovado ou reprovado).

## Estrutura do projeto

- `aluno.py` — estrutura de dados e regras relacionadas ao aluno.

## Como executar

```
python aluno.py
```
